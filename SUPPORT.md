## Getting Help

### 1. Check the Documentation

The [NETTRADES.AI Documentation](https://nettrades.github.io/nettrades-platform/) covers:

- [User Guide](https://nettrades.github.io/nettrades-platform/user/) – For end-users
- [Developer Guide](https://nettrades.github.io/nettrades-platform/developer/) – For developers
- [Operations Guide](https://nettrades.github.io/nettrades-platform/operations/) – For system administrators
- [FAQ](https://nettrades.github.io/nettrades-platform/user/faq/) – Frequently asked questions

### 2. Search GitHub Issues

Many common issues have already been reported and resolved. Before opening a new issue, please search the existing issues:

- [Open Issues](https://github.com/nettrades/nettrades-platform/issues)
- [Closed Issues](https://github.com/nettrades/nettrades-platform/issues?q=is%3Aissue+is%3Aclosed)

### 3. Join the Community

Connect with other users and contributors:

- **Discord**: [discord.gg/nettrades](https://discord.gg/nettrades) – Real-time chat
- **GitHub Discussions**: Ask questions and suggest features

### 4. Open an Issue

If you've found a bug or have a feature request, please open an issue on GitHub:

1. Go to [GitHub Issues](https://github.com/nettrades/nettrades-platform/issues)
2. Click **New Issue**
3. Choose the appropriate template:
   - **Bug Report** – For problems with the software
   - **Feature Request** – For new features or improvements
4. Fill in the details:
   - **Title**: Clear and descriptive
   - **Description**: What happened, steps to reproduce, expected behaviour
   - **Environment**: What OS, version, and deployment type you're using
5. Submit the issue

## Support Policy

### Community Support (Free)

Community support is provided by volunteers and maintainers. Response times vary depending on availability.

- GitHub Issues: Maintainers aim to respond within 48 hours
- Discord: Community members often respond quickly
- Documentation: Always up to date with the latest release

### Commercial Support (Paid)

Commercial support is available for enterprise customers and includes:

- SLA-backed response times
- Dedicated support engineers
- Priority bug fixes
- Custom development and consulting

For commercial support, contact [support@nettrades.ai](mailto:support@nettrades.ai).

## Security Issues

If you discover a security vulnerability, **please do not** open a public issue. Instead, report it privately:

1. Send an email to [security@nettrades.ai](mailto:security@nettrades.ai)
2. Provide:
   - Description of the vulnerability
   - Steps to reproduce (proof of concept, if possible)
   - Potential impact
   - Any suggested mitigation
3. We will acknowledge your report within 48 hours

[Full Security Policy →](https://nettrades.github.io/nettrades-platform/governance/security/)
