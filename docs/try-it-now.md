## Option 3: Quick Interactive Tour

### 1. Ask the AI a Question

1. Click the chat bubble in the bottom-right corner.
2. Type a question, e.g., "Find me a Python developer."
3. Watch the AI respond with a ranked list of candidates.

### 2. Post a Test Job

1. Go to **Jobs** → **Post a Job**.
2. Fill in the details:
   - **Title:** "Test Job – Python Developer"
   - **Description:** "We need a Python developer..."
   - **Required Skills:** "Python, Django"
3. Click **Post Job**.
4. Click **Match Candidates** to see the AI find matches.

### 3. Ask an Expert

1. Click the **Ask Someone** button.
2. Describe your question.
3. See the list of matched experts.
4. Start a session (no payment required on the demo instance).

### 4. Share a GPU (Simulated)

1. Go to **GPU Manager** → **Share GPU**.
2. Download the installer (simulated on the demo instance).
3. See how the node registers and becomes available.
