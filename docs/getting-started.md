# Getting Started with NETTRADES.AI

Welcome! This guide helps you take your first steps with NETTRADES.AI, regardless of your role.

---

## Choose Your Path

### 🚀 I want to try the platform (no installation)

If you just want to see what NETTRADES.AI can do without setting anything up:

→ Go to the [Try It Now](/try-it-now) page

---

### 👤 I want to use the platform (as a company, freelancer, or job-seeker)

If you want to:

- Post jobs or find candidates
- Find freelance projects or submit proposals
- Apply for jobs
- Get expert help ("Ask Someone")
- Share or rent GPUs

→ Read the [User Getting Started Guide](/user/getting-started)

---

### 👨‍💻 I want to develop or extend the platform

If you want to:

- Build custom LangGraph agents
- Create new Odoo modules
- Extend the GPU Admin Panel
- Contribute to the project

→ Read the [Developer Getting Started Guide](/developer/getting-started)

---

### 🛠️ I want to deploy and run the platform

If you want to:

- Deploy the platform on a single server
- Deploy on Kubernetes
- Add GPU nodes
- Manage and monitor the system

→ Read the [Operations Quick Start Guide](/operations/quick-start)

---

### 📋 I want to contribute to the project

If you want to:

- Report bugs
- Submit code or documentation
- Join the community

→ Read the [Contributing Guide](/governance/contributing)
