# In nettrades-setup.sh
# With --auto (or without any flags), Fine-Tuning Is Skipped by Default
# In the script I provided:
# The --auto flag only disables interactive prompts.
# WITH_FINETUNE defaults to false.
# To enable fine-tuning, you must explicitly pass --with-finetune or answer y in interactive mode.
# So running:
# bash
# ./nettrades-setup.sh all --auto
# will not install the heavy packages (torch, unsloth, axolotl). It will only install the base requirements (requirements-base.txt).
# If you want both automation and fine?tuning:
# ./nettrades-setup.sh all --auto --with-finetune
# Summary of Flags
# Flag	                Effect
# --auto	        No interactive prompts; uses defaults.
# --with-finetune	Installs large ML packages (torch, unsloth, axolotl).
#(no flag)	        Fine-tuning skipped by default.
#
# requirements.in ? requirements-lock.txt ? Used for production installation (pinned versions)
# requirements-dev.txt ? Used for development (loose versions)
